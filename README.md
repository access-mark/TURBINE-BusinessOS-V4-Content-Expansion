# TURBINE BusinessOS Website V4 — full-adoption product discovery

Static GitHub Pages website. Upload all contents of this folder to repository root and enable GitHub Pages from the root of the main branch.

## Product positioning
TURBINE is one complete BusinessOS adopted as the primary business operating environment. It is not middleware, an integration consultancy, or an e-commerce storefront.

## Content
16 dedicated industry pages, business-size use cases, full adoption, platform, capabilities, actual CP12 screenshots, DataPort, governance, TURBINE Command, pricing approach and trust pages.

## Release constraints
No production tenant provisioning, payment or lead delivery is implied. Forms remain non-submitting until an approved destination is configured. Every specialist workflow must be reconciled with qualified product evidence before launch. The source screenshot content contains synthetic records.

## Branding
Two transparent theme-responsive logo assets are derived from the user-supplied logo and prior logo crop. Check logo fidelity on dark and light themes; original source assets remain in the user's project.

## Responsive design
Fluid max-width layout; min-width:0 on grid children; media breakpoints at 1050, 850 and 570px; viewport-fit; image containment; reduced-motion support. Browser acceptance tests at 320, 375, 390, 768, 1024, 1440 and 200% zoom remain required.
